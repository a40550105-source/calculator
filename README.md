# Python Calculator

A command-line calculator that supports addition, subtraction, multiplication,
division, unary signs, and parentheses.

Run it with Python 3:

```sh
python3 calculator.py
```

Enter an expression at the prompt, or type `q` to quit. For example:

```text
> 2 + 3 * (4 - 1)
11
```

Run the tests with:

```sh
python3 -m unittest
```
